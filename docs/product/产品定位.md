# AI Agent 防火墙产品定位

## 一句话

AgentBulwark（智垒）是本地优先的 AI Agent 运行时防火墙：保护模型请求、外部上下文、模型输出和工具调用，让每一次行动在执行前可控、执行中可见、执行后可验证。

## 首个用户

5–100 人、已经使用 MCP 或 Tool Calling、需要接入私有/国产模型，并需要安全评审或审计证据的 AI 开发团队。

## 生产主链

```text
Agent
→ OpenAI Gateway
→ 会话与请求绑定
→ Provider 固定出口
→ 模型响应与 Tool Call 检查
→ ALLOW / DENY / ASK / ISOLATE 决策
→ MCP Gateway 或受控运行时
→ 执行回执
→ Hash/HMAC 证据链
→ 控制台事件与离线验证
```

## 当前能力

- OpenAI 兼容 `POST /v1/chat/completions`，支持流式和非流式。
- OpenAI `POST /v1/responses`，提供非流式兼容入口。
- MCP Gateway 支持 stdio 与 Streamable HTTP。
- Agent、会话、Provider、MCP Server、工具和参数策略。
- `允许`、`拒绝`、`询问`、`隔离` 四态决策和一次性审批绑定。
- 执行回执、Hash/HMAC 审计链、离线证据验证。
- Provider 固定主机、协议、端口和路径，默认拒绝重定向与未登记目标。
- 本地控制台提供防护、事件、设置三个正式页面。

## 明确边界

AgentBulwark（智垒）是 AI Agent 运行时防火墙，不是攻击实验室、工具目录、任意代码执行器或通用内容分类器。文本过滤只负责输入、上下文和输出检测，最终边界由身份、策略、Schema 和 MCP 执行闸门共同决定。Hash/HMAC、Trace 和执行回执是防护结果的审计证明，不是产品主语。研究与历史资料不被默认 API、控制台构建或测试导入。

## 可信度口径

来源状态只允许：

- `proved`：客户端提供一次性关联凭证，网关完成密码学验证。
- `correlated`：依据会话、工具、参数和时间窗口完成关联，但没有来源密码学证明。
- `unknown`：无法可靠关联。高风险工具默认阻断或要求审批。

界面使用“对象 + 状态 + 下一步”表达事实，例如“已阻断 · 工具目标超出 Agent 权限”和“已关联，未证明”。不把模型拒答、规则命中或相关性推断描述成已执行或来源已证明。
