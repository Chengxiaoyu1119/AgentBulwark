# 安全边界

本文档描述当前单机版 Agent 网关的真实安全边界，不包含历史实验、容器部署或任意命令执行能力。

## 运行边界

- 默认只监听 `127.0.0.1`，本地控制台直接进入，不把本地免登录扩展到局域网。
- 生产模式必须配置 Bearer Token；缺少必要密钥时拒绝启动。
- Provider 与 MCP 凭证只从根目录 `.env` 或后端进程环境变量读取，前端只显示引用和脱敏值。
- Provider 出口固定主机、协议、端口和路径，禁止自动重定向与系统代理转发凭证。
- 运行数据、SQLite 数据库和审计回执只写入 `apps/api/runtime/`。

## 行动控制

- OpenAI 兼容请求先经过输入检查，再访问已登记 Provider。
- Tool Call 必须经过工具注册表、参数 Schema、目标策略和 Agent 权限检查。
- 策略结果只有 `ALLOW`、`DENY`、`ASK`、`ISOLATE` 四态，冲突按拒绝优先处理。
- `ASK` 产生一次性审批凭证；参数、策略版本、Agent、会话或目标变化后凭证立即失效。
- `DENY` 不触发工具副作用；`ISOLATE` 不会直接进入高权限执行路径，是否继续由隔离边界的具体契约决定；未知工具、畸形参数和策略错误默认拒绝。
- 真实执行完成后写入执行回执，并把请求、响应、参数、策略和结果绑定到审计链。

## 证据与日志

- 审计记录使用 HMAC 链式签名，支持重启后的离线验证。
- 未经密码学关联的客户端来源只能标记为 `correlated` 或 `unknown`，不能显示为“来源已证明”。
- 日志、浏览器产物和错误响应不得包含 API Key、Agent Token 或 HMAC 密钥。
- 证据验证失败、数据库损坏和外部依赖错误均默认阻断执行，不静默放行。

## 报告漏洞

请通过 GitHub Security Advisories 私密提交鉴权绕过、策略绕过、审计链伪造、回放或凭证泄漏问题，并附最小复现步骤和影响范围。
