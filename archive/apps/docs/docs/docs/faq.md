# 常见问题

## 没有真实模型密钥能运行吗

可以。后端会回退到本地模拟模型。攻击脚本、监督决策、审计日志、告警和报告仍然可用。

## 页面能打开是否代表后端在线

不一定。控制台在后端离线时会使用内置样本数据。要确认后端在线，访问：

```text
http://127.0.0.1:8012/api/health
```

或者查看控制台顶部是否有后端不可用提示。

## 为什么有 `apps/api` 而不是 `backend`

仓库里有多个可运行应用：API、控制台、官网和文档站。`apps/api` 明确表示这是对外提供 HTTP 接口的应用，而不是所有后端代码的泛称。

## 为什么控制台叫 `apps/console`

控制台是主操作界面，但不是唯一前端。官网和文档站也是前端应用，所以用 `console` 区分运行控制台。

## 根目录 `docs` 和 `apps/docs` 有什么区别

`apps/docs` 是正式文档站，面向开发者、评审和接入方。根目录 `docs` 保留历史开发记录、方案草稿和比赛过程材料，不直接作为文档站发布源。

## 项目会发送真实邮件吗

不会。邮件工具只写入本地假 outbox，用于复现实验和审计展示。

## 项目会读取电脑上的真实文件吗

不会主动读取真实文件。文件工具应限制在本地沙箱目录内，越界路径会被策略拒绝。

## 什么时候需要 API Token

只有开启 API 鉴权时才需要 API Token。如果设置 `AGENT_SUPERVISOR_AUTH_DISABLED=true`，控制台和外部 Agent 调用后端接口时不需要携带 token。这个开关不影响真实大模型接口，DeepSeek、智谱是否可用由对应模型密钥和 `MODEL_REAL_API_ENABLED` 决定。

## OpenClaw 是强依赖吗

不是。项目提供 OpenClaw 兼容事件入口和插件包生成能力，但通用 `/api/runtime/evaluate` 接口也可以接入其他 Agent 框架。

## 报告数据为什么会变化

报告基于本地运行记录和沙箱数据生成。清空数据库、切换沙箱或重新运行脚本后，统计结果会变化。这是预期行为。
