# Agent Security Supervisor

Agent Security Supervisor（智安哨）是本地运行的 Agent 工具调用监督系统。它用于复现 LLM Agent 在文件、邮件、API、代码执行、记忆和环境上下文中的风险，并在工具执行前给出可审计的安全决策。

系统由四部分组成：

- 一个 FastAPI 监督服务，负责接收工具调用事件并返回决策。
- 一个 React 控制台，用于运行脚本、查看审计日志、调整策略；报告和证据只在需要复核或交付时按需生成。
- 一组本地沙箱工具和假比赛数据，用于安全复现实验。
- CLI 和文档站，用于批量评测、接入验证和交付材料生成。

:::note 适用范围
这个项目适合做 Agent 安全研究、工具调用风控原型、比赛作品演示和本地集成验证。它不是托管式 SaaS，也不连接真实比赛平台、真实邮箱或真实用户数据。
:::

## 核心问题

传统的 LLM 安全检查多集中在输入和输出。Agent 接入工具后，风险会进入执行层：模型可能读取文件、调用 API、发送邮件、运行命令或写入长期记忆。智安哨把检查点放在 Agent 和工具之间，对每次工具调用记录上下文、参数、策略命中、风险分、异常信号和最终决策。

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 攻击面研究 | 覆盖提示注入、模型越狱、数据泄露、滥用风险、工具调用劫持、记忆中毒和环境感知污染 |
| 脚本复现 | 内置 22 个攻击脚本，可单次运行，也可做有防护/无防护对比 |
| 工具调用监督 | 对工具调用输出允许、拒绝、询问和隔离四类决策 |
| 审计留痕 | 保存调用参数、策略命中、风险分、异常分、建议和审计 hash |
| 外部接入 | 提供 OpenClaw 风格事件入口、通用 Agent 接入包和插件包生成命令 |
| 按需证据材料 | 在复核、答辩或提交时生成攻击面证据包、误报评测、策略消融、异常阈值校准和赛前体检材料 |

## 典型工作流

```text
选择攻击脚本
-> 运行无防护复现
-> 开启监督策略后重跑
-> 查看工具调用审计
-> 检查告警和人工复核项
-> 导出报告或证据包
```

外部 Agent 接入时，工作流更简单：

```text
Agent 准备调用工具
-> 将工具名、参数和上下文发送给监督服务
-> 根据返回决策继续、停止、转人工或隔离执行
-> 保存审计记录
```
