# 防御策略

策略层负责把工具调用事件转换成安全决策。每条策略都有默认决策、启用状态和说明；运行时还会结合风险评分和异常检测结果生成审计证据。

策略配置位于：

```text
apps/api/agent_supervisor/config/policies.json
```

## 内置策略

| 策略 ID | 名称 | 默认决策 | 作用 |
| --- | --- | --- | --- |
| `path-boundary` | 文件沙箱边界 | 拒绝 | 禁止读取沙箱外路径、路径穿越和敏感目录 |
| `dangerous-command` | 危险命令拦截 | 拒绝 | 拦截删除、格式化、联网下载、提权等破坏性命令 |
| `code-sandbox` | 代码执行沙箱 | 隔离 | 代码执行默认进入沙箱，只允许白名单命令真实运行 |
| `external-mail` | 邮件外发询问 | 询问 | 外部收件人邮件需要人工确认，默认只写入假 outbox |
| `sensitive-api` | 高敏 API 审计 | 拒绝 | 禁止无授权访问队伍、提交物、成绩榜、赛题种子和管理员接口 |
| `memory-write` | 记忆写入隔离 | 隔离 | 含绕过权限、隐藏动作或提升权限的记忆写入进入隔离区 |
| `memory-read-sensitive` | 敏感记忆读取拦截 | 拒绝 | 拦截 secret、token、team、flag、submission 等敏感记忆检索词 |
| `jailbreak-filter` | 越狱提示过滤 | 拒绝 | 识别忽略系统规则、扮演无限制模型等越狱提示 |
| `model-output-filter` | 模型输出过滤 | 拒绝 | 拦截训练数据抽取、敏感样例逐字复述和高风险绕过指导 |
| `bulk-action-review` | 批量动作复核 | 询问 | 批量导出、批量外发、未登记外部用途需要人工复核 |
| `tool-return-trust` | 工具返回低信任隔离 | 隔离 | 工具返回内容不能作为授权或策略覆盖依据 |
| `environment-trust` | 环境信息低信任隔离 | 隔离 | 环境变量和配置只能作为低信任上下文 |
| `anomaly-detection` | 轻量异常检测 | 询问 | 固定规则未命中但工具、参数、上下文组合异常时触发复核 |

## 决策语义

| 决策 | 后续处理 |
| --- | --- |
| 允许 | 可执行工具，并保存审计记录 |
| 拒绝 | 不执行工具，返回阻断原因和修正建议 |
| 询问 | 生成待复核项，由安全人员批准或驳回 |
| 隔离 | 在受限环境或低信任区处理，结果不能直接覆盖可信上下文 |

## 策略管理

控制台的“防御策略中心”可以查看和调整策略。API 也提供策略更新接口：

```text
PATCH /api/policies/{policy_id}
PATCH /api/policy_settings
GET   /api/policies/versions
```

开启 API 鉴权时，策略修改需要具备 `admin` 角色。关闭 API 鉴权时，后端会按管理员权限处理控制台请求，适合公开演示或自用部署；这不会影响大模型接口调用。
