# 系统架构

Agent Security Supervisor 采用多应用目录。每个可单独运行的应用都放在 `apps/` 下，根目录只保留统一脚本、项目说明和历史材料。

```text
agent-security-supervisor/
├─ apps/
│  ├─ api/        # FastAPI 监督服务、沙箱工具、评测和报告生成
│  ├─ console/    # React 控制台
│  ├─ www/        # 项目官网介绍页
│  └─ docs/       # Docusaurus 文档站
├─ docs/          # 历史开发记录、比赛材料和过程文档
├─ scripts/       # CLI 包装、自审和治理脚本
└─ package.json   # 根目录统一命令入口
```

## 组件职责

| 组件 | 职责 |
| --- | --- |
| `apps/api` | 接收工具调用事件，执行策略判定，读写运行记录，生成报告和提交材料 |
| `apps/console` | 提供研究控制台，支持脚本运行、策略管理、审计查看、报告展示 |
| `apps/www` | 面向访问者的项目介绍页，不承载运行逻辑 |
| `apps/docs` | 面向开发者和评审的正式文档站 |
| `docs` | 历史资料和过程记录，不作为正式文档站内容源 |

## 请求生命周期

```text
Agent 或控制台发起工具调用
-> POST /api/run、/api/runtime/evaluate 或 /api/integrations/openclaw/events
-> FastAPI 路由解析请求
-> supervisor 计算策略命中、风险分和异常信号
-> 返回允许、拒绝、询问或隔离
-> 写入审计日志、告警、复核项和运行结果
-> 控制台实时展示结果；需要复核或交付时再由控制台/CLI生成报告
```

## 监督决策

| 决策 | 含义 | 常见场景 |
| --- | --- | --- |
| 允许 | 当前调用未触发高风险策略，可继续执行并记录审计 | 读取公开材料、查询非敏感接口 |
| 拒绝 | 调用越界或命中明确禁止项，应停止执行 | 读取敏感路径、访问管理员接口、运行危险命令 |
| 询问 | 风险依赖业务上下文，需要人工确认 | 外部邮件、批量导出、异常组合调用 |
| 隔离 | 调用可在受限环境中处理，结果不能直接进入可信链路 | 代码执行、可疑记忆写入、不可信工具返回 |

## 数据边界

项目默认只使用本地沙箱：

- 文件在 `apps/api/sandbox/workspace` 下模拟。
- 邮件写入假 outbox，不发送真实邮件。
- API 数据来自本地 fixtures 和模拟比赛数据。
- 代码执行受路径、命令白名单和超时限制。
- 模型密钥只从环境变量读取，不写入前端源码。

## 设计取舍

- 控制台使用 React 和 Vite，启动快，适合本地演示和调试。
- API 使用 FastAPI，路由清晰，便于对外提供监督接口。
- 文档站独立于控制台，避免把使用手册和运行界面耦合。
- CLI 通过 `scripts/agent-supervisor-cli.mjs` 转发到 Python 模块，方便 Windows 和 npm 工作流统一使用。
