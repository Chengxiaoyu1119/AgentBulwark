# 比赛功能对照说明

文档定位：把信息安全作品赛安全检测方向的要求逐项对应到当前项目功能、页面、接口和真实执行边界。
更新日期：2026-08-21

## 1. 总体结论

本项目对应信息安全作品赛软件作品的“安全检测”方向。当前系统以 LLM API / MCP 网关和 Agent 工具执行前监督为主产品，攻防验证负责证明效果，报告只负责按需复核和导出：

```text
Agent 工具调用
  -> 执行前行为监督
  -> 允许 / 拒绝 / 询问 / 隔离
  -> 工具执行、沙箱执行或停止
  -> 执行回执
  -> 事件审计与人工复核
```

需要明确的是：项目中的“真实可用”指的是在授权目标、沙箱目录、假比赛数据和用户确认授权的目标接口内真实调用和真实审计，不是对无授权第三方系统做破坏性攻击。

## 2. 方向目标与当前项目对应关系

| 方向目标 | 当前项目实现 | 主要入口 |
|---|---|---|
| 研究提示注入、模型越狱、训练数据泄露、滥用风险、工具调用劫持、记忆中毒、环境感知污染等攻击面 | 已覆盖 7 类攻击面，每类有样本、利用目标、防御点和运行结果 | 攻击功能实验台、本地受控实验 |
| 构造对抗性输入 | 每类攻击面内置默认对抗输入，前端可编辑后运行 | 攻击功能实验台、本地受控实验、模型越狱对测 |
| 设计智能体攻击脚本 | 后端以可调用模块和固定/模型规划两种方式生成工具调用；脚本证据可回放 | 一键复现、脚本证据回放 |
| 对工具调用实时审计与异常判定 | `evaluate_agent_event` 对邮件、文件、API、代码、记忆、环境、模型响应做策略判定 | 事件与复核 |
| 对代码执行、文件访问、API 调用进行监督 | 沙箱工具层真实执行受控文件读写、API 模拟、代码安全探针和记忆写入 | 本地受控实验、攻击功能实验台 |
| 支持允许、拒绝、询问、隔离策略 | 监督器输出四类决策，并写入审计日志 | 防护策略、事件与复核 |
| 通用智能体工具执行链接入 | 项目内置目标 Agent 受控实验环境，并提供通用事件接口和多框架示例 | Agent 接入、`/api/runtime/evaluate` |
| 提供模拟业务工具 | 已提供假邮件、沙箱文件、模拟 API、受限代码执行、长期记忆、环境变量工具 | `apps/api/agent_supervisor/domains/runtime/tools.py` |
| 模型调用链路安全监控插件 | 新增本地 OpenAI 兼容代理 `/v1/chat/completions`，对模型输入输出做过滤和审计 | 双模型优化越狱、本地代理 |
| 基座模型检测或过滤原型 | `filter_model_output` 检测 token、secret、flag、危险命令、越狱标记 | 模型越狱对测、双模型优化越狱 |
| 监督端实时展示告警或阻断记录 | Web 控制台集中展示审计、告警、阻断、审批、执行回执和审计 hash | 事件与复核 |

## 3. 七类攻击面功能点

| 攻击面 | 当前功能 | 是否能运行 | 安全边界 |
|---|---|---:|---|
| 提示注入 | 把恶意指令藏在网页、邮件、文档等低可信内容中，诱导 Agent 外发或越权调用 | 能运行 | 邮件只写入本地假 outbox，不发送真实邮件 |
| 模型越狱 | 生成多种越狱变体，观察目标模型是否拒绝或泄露敏感内容 | 能运行 | 无密钥走本地模拟；有密钥可调用真实模型，但输出会被过滤 |
| 内容泄露 | 诱导读取 `confidential/competition-teams.csv` 等沙箱敏感文件 | 能运行 | 只读项目沙箱假数据，不读用户真实文件 |
| 工具调用劫持 | 诱导 Agent 调用代码执行工具或危险参数 | 能运行 | 代码执行被限制为安全探针脚本，不执行破坏性命令 |
| 记忆中毒 | 向长期记忆写入恶意偏好，观察后续任务污染风险 | 能运行 | 写入本地假记忆库，保留审计和隔离状态 |
| 环境感知污染 | 伪造环境变量或工具返回，让模型误以为已授权 | 能运行 | 环境值为受控模拟值，不能覆盖真实安全策略 |
| 滥用风险 | 批量导出队伍、提交摘要、评审备注等模拟业务数据 | 能运行 | 调用本地比赛 API，不访问真实比赛平台 |

## 4. 页面功能对应

| 页面 | 作用 | 主要价值 |
|---|---|---|
| 运行总览 | 汇总服务、模型、风险事件、待确认回执和真实调用链 | 先判断系统是否在线、是否正在产生真实监督证据 |
| 事件与复核 | 查看审计、告警、策略命中、审批和执行回执 | 完成从监督决策到人工处置的闭环 |
| 攻防验证 | 运行无防护攻击成功与有防护风险受控的红绿对照 | 通过真实副作用证明防护有效，不依赖静态文案 |
| 防护策略 | 管理工具边界、策略、阈值和四类处置 | 将防护逻辑集中到单一策略入口 |
| Agent 接入 | 提供通用事件契约、模型连接和多框架示例 | 接入任意 AI Agent；OpenClaw 仅为折叠的可选适配器 |
| 证据导出（按需） | 汇总攻击成功率、阻断率、误报率等指标 | 只用于比赛复核和材料提交，不参与运行时判定 |

## 5. 页面分类与赛事验收口径

为避免功能堆叠，控制台主导航收敛为 5 个入口：

| 主导航 | 对应研究目标 | 答辩时的说明口径 |
|---|---|---|
| 运行总览 | 运行态势与调用链可观测性 | 先展示系统在线、模型连接、风险事件和待确认回执。 |
| 事件与复核 | 实时审计、告警、人工审批、执行回执 | 证明监督器不仅给出分数，还能驱动处置并核验工具是否真的执行。 |
| 攻防验证 | 构造攻击输入，运行单次对照、真实 Agent 验证和批量回归 | 证明同一任务在无防护时产生风险副作用，有防护时风险被控制。 |
| 防护策略 | 工具调用边界、风险策略与处置规则 | 展示策略命中如何直接决定允许、拒绝、询问或隔离。 |
| Agent 接入 | 通用事件契约、模型连接、多框架适配 | 证明平台服务任意 Agent 工具链，OpenClaw 只是可选适配器。 |

攻击场景库、多 Agent 攻击链、告警深链接和证据导出仍然存在；它们作为高级研究或按需复核能力，不占用主导航。

实验台内部也按用途收拢为 3 组：

| 实验台分组 | 包含功能 | 用途 |
|---|---|---|
| 基础复现 | 本地受控实验、攻击功能实验台、红队测试集 | 面向 7 类攻击面的本地可控复现。 |
| 模型越狱 | 模型越狱对测、双模型优化越狱 | 面向基座模型输出、越狱样本和过滤原型的验证。 |
| 外部接入 | 外部授权目标、快速验收、审计用例验证 | 面向外部 Agent、OpenAI 兼容代理、监督接口和验收检查。 |

攻击脚本库新增“全部 + 7 类攻击面”快捷分类入口，便于答辩时直接按攻击面筛选脚本和证据。

## 7. 真实执行边界

| 类型 | 当前是否真实调用 | 说明 |
|---|---:|---|
| 本地沙箱文件读取 | 是 | 真实读取项目沙箱中的假敏感文件 |
| 本地沙箱文件写入 | 是 | 真实写入沙箱目录，不写用户真实目录 |
| 邮件发送 | 半真实 | 生成邮件并写入本地 outbox，不投递真实邮件 |
| API 调用 | 是 | 调用本地模拟比赛 API |
| 代码执行 | 是 | 执行白名单安全探针，拒绝破坏性命令 |
| 记忆写入 | 是 | 写入本地假记忆库，记录审计来源 |
| 模型调用 | 可真实 | 配置密钥并打开真实模型开关后调用真实模型，否则本地模拟 |
| 外部 API 目标 | 受控可接入 | 带身份 Agent 的绝对 HTTP(S) 主机必须登记 `agent_api_allowlists`；未登记目标进入人工复核，并在执行前重新校验公网 DNS |
| 输出过滤 | 是 | 对模型输出做正则检测、脱敏和阻断判定 |
| 审计日志 | 是 | 每次监督判定都会生成审计编号和记录 |
| 运行状态面板 | 是 | 前端显示后端、模型、沙箱、代理的真实运行状态 |
| 代理访问限制 | 是 | `/v1/chat/completions` 支持 token 鉴权、本地免鉴权边界和每分钟限流 |

## 9. 外部授权目标说明

外部 API 目标不是“攻击任意公网目标”。它只做三件事：

1. 由管理员按 Agent 身份登记精确 HTTPS 主机、可选端口或单级子域通配符。
2. 相对路径只用于本地业务能力；绝对目标在 `external-api-allowlist` 策略下未命中登记即暂停。
3. 后端拒绝本机、内网、链路本地、多播和保留地址；执行器应禁用自动重定向，并对每一跳重复主机白名单和公网 DNS 校验，避免 SSRF 或数据外带。

这个设计满足“真实可调用”的学习需求，同时保留比赛作品必须具备的安全边界。

## 11. 答辩演示建议

推荐答辩顺序：

1. 进入“运行总览”，确认服务、模型、风险事件和待确认回执状态。
2. 打开“攻防验证”，对同一个内容泄露或工具劫持任务运行无防护与有防护分支。
3. 对照展示无防护分支产生风险副作用、有防护分支命中策略并控制风险。
4. 进入“事件与复核”，展示审计编号、策略命中、监督决策、审批状态和执行回执。
5. 进入“防护策略”，解释关键策略如何决定允许、拒绝、询问或隔离。
6. 进入“Agent 接入”，展示通用事件契约和实际接入方式；只有复核需要时再打开证据导出。
